# gamaerry.github.io

Portafolio personal, publicado con GitHub Pages en <https://gamaerry.github.io/>.

- `index.html`: portafolio.
- `rompecocos/`: página del juego y su política de privacidad (`rompecocos/privacidad.html`), enlazadas desde Google Play y Google Auth Platform.
- `googleXXXXXXXX.html`: archivo de verificación de Google Search Console. **No borrar**: si desaparece, Google retira la verificación del sitio.

Sin build: HTML y CSS estáticos. `.nojekyll` evita que GitHub Pages pase los archivos por Jekyll.
