# gamaerry.github.io

Portafolio personal, publicado con GitHub Pages en <https://gamaerry.dev/> (antes <https://gamaerry.github.io/>, que ahora redirige ahí).

- `index.html`: portafolio.
- `rompecocos/`: página del juego, su política de privacidad (`rompecocos/privacidad.html`) y sus términos de servicio (`rompecocos/terminos.html`), enlazados desde Google Play y Google Auth Platform.
- `googleefb2f4fbfbb5024e.html`: archivo de verificación de Google Search Console. **No borrar**: si desaparece, Google retira la verificación del sitio.

- `CNAME`: dominio propio de GitHub Pages. El DNS de `gamaerry.dev` está en Cloudflare (registros A/AAAA de GitHub Pages y `www` → `gamaerry.github.io`, sin proxy).

Sin build: HTML y CSS estáticos. `.nojekyll` evita que GitHub Pages pase los archivos por Jekyll.
